# Technical Specification Document (TSD): Finance Buddy

## 1. Tech Stack Overview
*   **Framework:** Next.js 14+ (App Router)
*   **Styling:** Tailwind CSS
*   **UI Components:** shadcn/ui (Radix UI base), lucide-react (Icons)
*   **Database & Auth:** Supabase (PostgreSQL)
*   **AI Models:** Groq SDK (`llama-3.2-11b-vision-preview` for Vision, `llama3-8b-8192` for Text)
*   **Email Service:** Resend SDK
*   **Data Visualization:** Recharts

## 2. Database Schema (Supabase)
The application relies on a single primary table linked to the Supabase Auth system.

**Table:** `user_transactions`
*   `id` (uuid, default: gen_random_uuid(), primary key)
*   `user_id` (uuid, foreign key references `auth.users(id)`, not null)
*   `amount` (numeric, not null)
*   `user_note` (text, nullable)
*   `category` (text, not null) - *Generated by Groq Vision or Manual Fallback*
*   `created_at` (timestamp with time zone, default: now(), not null)

**Row Level Security (RLS):**
*   RLS MUST be enabled on `user_transactions`.
*   Policy: Users can only `SELECT`, `INSERT`, `UPDATE`, and `DELETE` rows where `auth.uid() = user_id`.

## 3. Backend API Routes (Next.js Route Handlers)

### A. `/api/analyze` (POST)
*   **Purpose:** Accepts a base64 image string from the client, sends it to Groq Vision to categorize the spend.
*   **Payload:** `{ image: "base64_string", amount: numeric }`
*   **Logic:** 
    *   Initialize Groq client.
    *   Use model `llama-3.2-11b-vision-preview`.
    *   Prompt: *"Analyze this image representing a transaction context for an amount of {amount}. Classify this into exactly ONE of these categories: Food & Beverage, Transport, Groceries, Shopping, Utilities, Entertainment, or Miscellaneous. Return ONLY the category name as a plain string, nothing else."*
*   **Response:** `{ category: "String" }`

### B. `/api/summary` (POST)
*   **Purpose:** Aggregates today's spending, generates an AI tip, and emails the user.
*   **Payload:** `{ userId: "uuid", email: "user@example.com" }`
*   **Logic:**
    *   Query Supabase server-side for all transactions by `userId` where `created_at` is today.
    *   Aggregate total spend and group by category.
    *   Send aggregated text to Groq (`llama-3.1-8b-instant`).
    *   Prompt: *"The user spent X total today across these categories: [Categories]. Write a 1-sentence, slightly snarky but helpful financial tip."*
    *   Use Resend to email the user a cleanly styled HTML email with the total and the Groq tip.
*   **Response:** `{ success: true, tip: "String" }`
